## 高程和估算

Mapzen Terrain Tiles 提供 Terrarium 编码 DEM。其基础数据包括历史 SRTM（2000 年 2 月），单瓦片的具体混合来源日期没有公开给出。本项目保留解码后的 `rawHeights`，将高程减去当地中位数作为场景高度，再进行轻微平滑和湖岸、建筑基底局部平整。网格为 125 × 165；重采样密度不等于原生测量精度。地形无垂直夸张。

370 栋建筑缺少高度、层数信息，按生活建筑 6 层、教学 5 层、文体 2 层、配套 3 层和层高 3.3 米估算。有 OSM 层数时按层数换算；少数地标依据照片人工调整。分类窗格、阳台、入口和屋顶是程序生成，未经过逐栋外立面测绘。第二教学楼的正侧立面依据不足，在资料中明确标为类型推定。

3,130 株植物是固定随机种子的示意配置，避开道路、建筑、水体与运动场，以映射绿地提高密度。树种、具体树位与高度不代表逐树调查。运动场保留 OSM 轮廓，细部铺装、标线属于表现性细节。

```sh
python3 -m venv work/venv
work/venv/bin/pip install -r scripts/requirements.txt
npm run data:restore                  # 复现仓库中的快照
work/venv/bin/python scripts/prepare_geodata.py
```
