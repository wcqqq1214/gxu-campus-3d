## 高程和估算

Mapzen Terrain Tiles 提供 Terrarium 编码 DEM。其基础数据包括历史 SRTM（2000 年 2 月），单瓦片的具体混合来源日期没有公开给出。本项目保留解码后的 `rawHeights`，将高程减去当地中位数作为场景高度，再进行轻微平滑和湖岸、建筑基底局部平整。网格为 125 × 165；重采样密度不等于原生测量精度。地形无垂直夸张。

当前 339 栋建筑仍按用途类型默认层数和层高 3.3 米估算；其余建筑也不等于实测。有 OSM 层数时按层数换算，少数地标依据照片人工调整；11 条普通楼部分校准记录补充了校方文献层数与照片依据，主体高度仍为估算，详见 [楼栋校准记录](BUILDING_CALIBRATIONS.md)。普通建筑将用途分类与形制区分，食堂不再套用宿舍阳台规则；窗列使用目录层数。入口仍主要按最长外边中点示意，动物学院与农学院已按照片和映射凸部定位，仍非测绘。第二教学楼的正侧立面依据不足，在资料中明确标为类型推定。

普通建筑基础与近景共用屋顶形体。第五教学楼 `way/759129515` 和广西房地产及住宅研究会 `way/759132932` 的四坡顶形式来自既有 OSM `roof:shape=hipped`，屋脊抬升 2.3 米和具体坡度为展示估算；复杂屋顶限制在原轮廓内。其余无屋顶形制资料的普通楼采用明确标注为推定的平顶，不再按世界坐标轴方向自动生成坡顶。`buildings.json` 的 `form`、`archetype`、`roofBasis` 记录规则及依据；这次规则修正不等于完成楼层和入口的实景校准。

S2 的人工输入保存在 `data/building-overrides.json`，由稳定 ID 和轮廓摘要绑定。派生 `calibration.evidence` 逐项区分资料明确、OSM 采用和估算值；`review` 保存未确认的入口、立面、裙房与来源冲突。动物学院的高核心、低侧翼沿原轮廓分区，保留内院；侧翼层数、层高和分段尺寸为照片约束估算。项目册 PDF 创建时间为 2020 年、拍摄日期未知，不以此次 2026 年查阅日期证明近期外观。

2026-09-13 的后续清晰照片核对支持动物学院可见侧翼五层，以及中央正面八列窗格。中央第 11 边现采用有依据的列数与连续竖向分隔，窗宽高比例、构件尺寸、层高与近景窗内分格仍属估算或简化，见[中央窗格记录](ANIMAL_COLLEGE_GLAZING.md)。未入镜后翼和核心侧面不视作确认；来源目录仍为 68 条。

当前3,061株植物包括3,047株保留背景树和博萃路试点的14株行道树示意。背景按网格独立固定种子生成；试点以稳定道路线位和里程组织两侧树列，在局部替换3株背景树。全部候选继续经过最终占地、保留区与模型净空筛选。道路树列有校方文字和照片依据，树种模型、具体树位、间距与高度仍不代表逐树调查；实例朝向按树位稳定计算，树根高程由最终地形三角面生成。运动场保留OSM轮廓，细部铺装、标线属于表现性细节。
