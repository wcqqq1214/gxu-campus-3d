## 高程和估算

Mapzen Terrain Tiles 提供 Terrarium 编码 DEM。其基础数据包括历史 SRTM（2000 年 2 月），单瓦片的具体混合来源日期没有公开给出。本项目保留解码后的 `rawHeights`，将高程减去当地中位数作为场景高度，再进行轻微平滑和湖岸、建筑基底局部平整。网格为 125 × 165；重采样密度不等于原生测量精度。地形无垂直夸张。

370 栋建筑缺少高度、层数信息，按生活建筑 6 层、教学 5 层、文体 2 层、配套 3 层和层高 3.3 米估算。有 OSM 层数时按层数换算；少数地标依据照片人工调整。分类窗格、阳台、入口和屋顶是程序生成，未经过逐栋外立面测绘。第二教学楼的正侧立面依据不足，在资料中明确标为类型推定。

3,181 株植物是固定随机种子的示意配置，避开道路、建筑、水体与运动场，以映射绿地提高密度。树种、具体树位与高度不代表逐树调查。运动场保留 OSM 轮廓，细部铺装、标线属于表现性细节。

## 更新

### 东西田径场修订

2024 年校方[改造施工公告](https://www.gxu.edu.cn/info/1364/36345.htm)覆盖两处田径场和足球场，因此外观核对采用改造后的资料：[西场 2025 开学典礼](https://news.gxu.edu.cn/info/1002/42983.htm)、[2025 校运会](https://dqgc.gxu.edu.cn/info/1057/4415.htm)、[东场 2026 阳光缤纷跑](https://news.gxu.edu.cn/info/1002/43641.htm)。发布日、活动日和未知的单张照片拍摄日分列于来源表。

西场 `relation/12774259` 最后编辑于 2022-07-07，东场 `way/759193119` 最后编辑于 2019-12-28。两者不能称为 2026 年测绘成果；GeoJSON 原始内环和外形未修改。派生的 [sports.json](../public/data/sports.json)保留 ID、版本、外轮廓、方向、平整高程和估算参数。西场原有内环不再误判为可种树空地；地形按完整运动场平整，并以树冠半径排除边缘植被。此次仅移除 38 株场内及主席台附近的示意树，其他树位保留。

两处均按 8 道、1.22 米道宽建模；西场足球标线为 100×64 米，东场为 100×62 米。这些是适配公开轮廓的比例估算，不能用于核验正式 400 米跑道或比赛认证。东场照片未完整展示内场，不将其描述为逐细节照片复原。西场主席台绑定现有 OSM 屋盖 `way/948683815`，侧座席相对该屋盖布置，排数、尺寸、座椅构造按照片估算。

### 更新流程

```sh
python3 -m venv work/venv
work/venv/bin/pip install -r scripts/requirements.txt
npm run data:restore                  # 复现仓库中的快照
work/venv/bin/python scripts/prepare_geodata.py
npm run models:build
# 要获取实施时新的地图，显式刷新：
python3 scripts/fetch_geodata.py --refresh
work/venv/bin/python scripts/prepare_geodata.py
npm run models:build
```

刷新后需要更新来源记录、快照文件、文档统计与验收报告，重新检查 10 处地标的 ID 是否仍然有效。接口不完整、Overpass 返回 remark 或无要素时脚本拒绝写入半份数据。
