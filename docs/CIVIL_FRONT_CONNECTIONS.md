# 土木学院主门与附楼台阶的前场连接

2026-09-21，接续附楼东侧退台，处理两处通行断点：南侧东端主门与现有路面之间约2.3米的缺口、附楼宽下梯底边至同一路面约2.8米的缺口。只补有界的短铺地；整片前庭、环形园路和绿化仍待校准，不能据此认定整栋完成。

## 数据与生成

主门复用`front-connection`，限制于门洞中央柱间。附楼新增`terraced-stair-connection`，直接锚定`form.terracedStairs`的宽下梯底边；解析记录中只保存台阶锚点，不添加门洞、主入口或导航入口身份。该连接不接受单独改宽或虚构`entranceId`，宽度随已校准下梯。

两种连接共用既有铺地、局部地形下削及道路接缝生成。准备阶段检查完整台阶/门口边界、现有道路修订、楼栋碰撞和其他台阶/外廊占地；构建阶段重新核对台阶锚点，拒绝使用过期派生数据。连接跟随修复后的前庭路面，两端校道接口原高度保持；接缝采用浅埋搭接应对独立GLB节点的毫米级压缩误差。

建筑、台阶和屋顶几何不变。新增两块铺地及道路接缝节点，局部地形与道路网格随之裁切；不移动道路或改变原始道路记录。

### 前庭道路网格修复

首版连接的[接缝检查失败](model-checks/refinement/s2-civil-front-connection-initial-geometry.json)。[修改前后射线取证](model-checks/refinement/s2-civil-front-connection-road-diagnosis.json)确认：主门前原路面内部已存在约0.384米的相邻三角面突跳，旧通用DEM采样加0.40米外偏还使部分路面明显悬空。首版连接沿用了该错误高度，不能验收。

在`paving-overrides`中增加明确的`groundedService`修复，保留`way/842784664`约309.606平方米的全部原轮廓，以实际地形三角面上方0.12米生成连续路面。第4、第10边仍接原校园主路，在3米范围内过渡到校道原高度，材质保持道路。先完成道路修复，再生成两处连接；其余原有铺地规则保持。

首次只用1米网格采样时，一处单元跨地形折线产生约2.18厘米贴地误差，保留[失败记录](model-checks/refinement/s2-civil-front-connection-road-grid-before-geometry.json)。随后将铺面沿实际地形三角面边界分割，使网格保留折线。0.12米偏移、1米网格和3米过渡都是数值建模参数，不是实测路缘或道路纵坡。

源模型通过后，原15位道路位置压缩仍在校道接口产生超出接缝容差的细缝，保留[压缩失败记录](model-checks/refinement/s2-civil-front-connection-road-compression-before-geometry.json)。全校道路统一改为20位虽通过几何检查，却使首屏达到6,503,324字节，[超过原6 MB预算](model-checks/refinement/s2-civil-front-connection-road-precision-budget.json)，因此撤回。最终沿用15位参数，只在导出时把目标路面及外围5米范围划入独立道路节点，以缩小量化范围；分块边缘保留0.2米浅埋搭接，竖向封边保持。地形仍为18位，源模型道路不因导出分块而拆散。最终以实际GLB复测接缝，而非只检查源模型。

## 验证范围

新增数据测试检查台阶底边全宽接合、旋转后关系保持、无新增入口身份，以及缺失锚点、改宽、过期路面和其他台阶阻挡的拒绝。生成小样覆盖斜路面接合、局部地形净空及外部地形保持。

实际连接检查门槛、台阶首级、道路原平面和接缝、铺地下净空及外围地形。门前有高顶板，因此障碍检查改为铺面以上0.03–2.1米的通行范围；门扇、门框所在薄层单独排除。该检查允许高于通行范围的真实顶板，不声称室内穿行或自动开门。

### 性能排查与网格开销

[首次性能汇总](model-checks/refinement/s2-civil-front-connection-initial-summary.json)中，精细档三轮为48/60/48 FPS，未通过原60 FPS基线的下降不超过10%门槛；流畅档为30/30/30 FPS。该失败记录保留。随后用原S0资产做[环境对照](model-checks/refinement/s2-civil-front-connection-s0-control-browser.json)，得到60/60/60与30/30/30 FPS，因此没有降低原验收标准。

排查还发现，贴地采样的浮点误差触发9,211片地形下削，但最大下削量只有0.00003814米。已限制仅对`groundedService`忽略不超过0.0001米的这类数值扰动，直接保留原地形；真实高差依然修复，小样同时验证两种情况。首屏从5,586,592降到5,326,632字节。此改动消除了可量化的冗余，首次低帧同时存在的桌面后台活动仍保留在采样记录中，不据此单独归因。

优化后的[最终汇总](model-checks/refinement/s2-civil-front-connection-summary.json)通过原预算：精细档60/60/60 FPS、流畅档30/30/30 FPS；相对原S0，三角形分别增加4.09%/9.30%，绘制次数增加3.84%/12.17%。24次CPU采样未捕获计时窗口内超过2%占用的Python/Blender进程，采样不代表完全没有其他后台活动。最终七张学院视图及图书馆手机回归已直接检查，报告指纹与提交资产一致。所有实现、提交与推送均在`dev`，不更新主分支。
