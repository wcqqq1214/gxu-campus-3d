# 土木学院北翼两端正面窗列

2026-09-21，北翼两端朝北的正面改为白色墙面和较稀疏的窗列，与中央外廊区分。三列、五列及全部尺寸均为照片分辨率约束下的估算，未把模糊影像解读为精确窗表。本批仍属局部校准，未计整栋完成。

## 依据与采用参数

[已定位的北侧全景](CIVIL_REAR_MASSING_EVIDENCE.md)显示北翼中央外廊两侧为前凸白色翼楼，正面以独立窗孔为主。[GX720来源](https://www.gx720.net/pano/viewer/?slug=pano-658)拍摄日期未知；原始切片与投影视图仅作本机参考，不作为公开纹理。

本批只覆盖 `north-rear` 的原外环第11、15边，保留转折侧墙、三层体量、红色坡屋顶和内院。

## 有界墙面材质与窗格

`facadeRules.wallFinish` 只允许共享的 `white`、`pink`、`stone`，且必须对应一个完整实体外墙面；不与凹廊、附加外廊或架空部分混用，阳台需显式关闭。解析与生成均检查完整墙面匹配。它直接改用原墙面的材质，不增加重叠薄板，不修改坐标、厚度和屋面。

`windowGrid` 的 `pilasterWidth`、`pilasterDepth` 同时为零时省略通高壁柱；两者一零一正、负数、布尔值及非有限值被拒绝。现有正值配置继续保留原柱列。本批两端正墙使用该无柱列模式，窗面和近景窗框复用现有组件。

同时修正窗格组件基础模型的玻璃绕序：根据立面切向及外法线翻转顶点，使玻璃朝向室外。已有数学学院三条、动物科学技术学院一条窗格立面也受此修正影响；它们的输入参数、源文件和近景资产未变。旧基础模型玻璃法线与外法线点积约−1，新版大于0.99；不将法线修复混同为这两栋的新立面校准。

## 验证

224项Python测试通过；新增数据检查覆盖完整墙面匹配、非法颜色、凹廊冲突及无柱列参数。84项独立生成检查覆盖旋转、正反立面及两个LOD：墙面材质修改不改变顶点和面，零尺寸柱列不生成几何，玻璃正面朝外。

[两端窗列专项](model-checks/refinement/s2-civil-wing-ends-geometry.json)在源、基础和近景各检查138处，核对24扇窗的双侧玻璃、上下实墙、窗间无壁柱及端部白墙。[旧窗列反例](model-checks/refinement/s2-civil-wing-ends-negative-geometry.json)在预计白墙处命中旧玻璃而失败。

[既有窗格专项](model-checks/refinement/s2-civil-wing-ends-grid-winding-geometry.json)冻结前一提交的四条立面参数，在数学学院和动物科学技术学院上层全部窗格分别检查56和96处，源、基础和近景均通过。底层入口遮挡不纳入这项法线检查。[旧基础模型反例](model-checks/refinement/s2-civil-wing-ends-grid-negative-geometry.json)因首处玻璃朝内而失败。

位置容差为源0.006、基础0.05、近景0.02米，窗面外向法线点积大于0.99。已有中央外廊、主楼圆窗及其余土木学院细节另作回归。

九张日夜、斜向、南侧回归和手机尺寸截图，以及图书馆手机尺寸回归图均已直接核看。源文件只有土木学院网格变化，3,063株树保持。69个GLB中仅基础模型和土木学院近景块变化，另外67个保持；基础模型另有数学学院、动物科学技术学院所在两块因玻璃绕序修正变化，其余91个节点保持。

首屏模型为5,374,984字节，比前一批增加180字节；最大普通近景块1,684,868字节。前端56项测试、类型检查、lint和Pages构建通过。[联合验收记录](model-checks/refinement/s2-civil-wing-ends-summary.json)保留资产指纹、全部几何检查及性能结果。

同浏览器、同环境各三次测量，精细档为60／60／60 FPS，流畅档为28／27／27 FPS。相对S0基线，精细档三角面与绘制调用中位数分别增加4.41%和4.20%；流畅档分别增加10.68%和14.83%，帧率中位数下降10%，达到允许下降上限。数字通过既定预算，但流畅档帧率和绘制调用均缺少稳定余量，不能据此承诺后续增加几何仍能通过。24次CPU快照在计时窗口内未发现超过记录阈值的Python或Blender活动；快照不等同于完整后台活动证明。

累计仍为21条部分对象记录、新增整栋验收零栋。学院楼完成后，按用户顺序继续实验大厅、新结构大楼。
