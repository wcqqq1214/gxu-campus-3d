# 新结构平台：大厅与北综合楼首批体量

2026-09-21，接续[新旧大厅识别](CIVIL_LAB_IDENTIFICATION.md)，将现有“大型结构试验研究平台综合楼” `way/957404988` 从统一五层拆分为四个高低体量。蓝顶实验大厅与九层北楼采用同一稳定 ID，不重复计算建筑数量。旧结构实验大厅仍是另一个待核对的历史对象。

后续已补入[大厅内缩蓝顶与深色屋面边带](CIVIL_PLATFORM_ROOF.md)、[北楼北窗网与东端实墙](CIVIL_PLATFORM_NORTH_FACADE.md)及[北楼屋顶附加体](CIVIL_PLATFORM_ROOFTOP.md)，并继续核对[圆柱玻璃门厅](CIVIL_PLATFORM_ENTRY_EVIDENCE.md)。下文保留首批体量验收记录；最新资产指纹与验证见后续专项。

## 本批模型

| 分部 | 采用高度 | 层数解释 | 屋面与细节 |
| --- | --- | --- | --- |
| 南实验大厅 | 13.2 米，估算 | 单层高空间，不添加中间整层楼板 | 蓝色平屋面简化，北向外墙 22 组窄高窗、每组上下两行；窗数、标高和尺寸均为估算 |
| 中间低实验区 | 10.8 米，估算 | 三层，待核实 | 浅色平顶，立面暂用通用窗列 |
| 西侧弧形门厅 | 7.2 米，估算 | 两层，待核实 | 保留原弧形外轮廓，入口细节待核对 |
| 北综合楼 | 29.7 米，估算 | 2014 年校方设计资料明确九层 | 九层乘 3.3 米推导高度，保留平顶占位，尚未校准屋顶突出物和完整立面 |

[2014 年校报](https://news.gxu.edu.cn/__local/8/C4/4D/0B1CE8B9D4B8389F21FF34B7030_FF27C11E_793A3.pdf?e=.pdf)说明南实验区、北九层办公区及门厅；[2022 年拆除采购公告](https://www.gxu.edu.cn/info/1364/30576.htm)附带的航拍支持已建蓝顶厅体与北部高楼的高低关系。原图及设计文字的时点、来源和限制详见对象识别文档。本次没有新增测绘依据，也不将历史照片当作 2026 年现状证明。

四部分严格覆盖原轮廓，合并对称差约 1.34×10⁻¹² 平方米，浮点误差量级的重叠约 4.55×10⁻¹³ 平方米。落模时发现原 GEOS 分割结果带有共线回折，影响外墙锚点；已用原始顶点与三处共享交点重建同一分区，未移动原外轮廓或放宽校验阈值。[候选平面脚本](../scripts/inspect_civil_platform_parts.py)仍只输出平面诊断，正式高度和窗列在 `data/building-overrides.json` 中。

分部平屋面新增可选 `finish: "blue-metal"`，只用于大厅屋面；其他建筑维持既有材质。基础与近景通过同一造型函数生成，避免切换时恢复为五层方块。

## 验证范围

- 229 项 Python、59 项 Node 测试，类型检查、lint、完整模型和 Pages 构建通过。
- [独立几何检查](model-checks/refinement/s2-civil-platform-geometry.json)在 Blender 源文件、实际基础和近景 GLB 上检查固定屋顶高度、三个分界两侧、外墙法线、大厅上部玻璃和下部实墙、内部无中间楼板。旧五层模型在同一检查中失败，构成有效反例。
- [数据检查](model-checks/refinement/s2-civil-platform-data.json)证明 448 栋中仅目标楼变化，原轮廓及道路、铺面、场地、地形和树位保持；430 栋普通建筑生成与两级几何回归通过，实际树冠净空及道路建筑检查通过。
- [源文件检查](model-checks/refinement/s2-civil-platform-source-preservation.json)确认 533 个非树对象中仅平台综合楼变化，其他 532 个对象及 3,063 株树的几何、材质、UV 和变换保持。
- [资产检查](model-checks/refinement/s2-civil-platform-assets.json)确认仅 `base.glb` 与 `chunk-n2-n3.glb` 变化，其他 67 个 GLB 和 93 个基础节点保持；全部 69 个模型与生产包一致。首屏 5,393,152 字节，增加 6,268 字节，最大普通近景区块 1,684,868 字节。
- [浏览器记录](model-checks/refinement/s2-civil-platform-final-context-browser.json)包含四个前后视角，以及植被开启、夜景、手机尺寸。东南角被原有邻楼局部遮挡，不作为南立面完整验收依据；俯视与东北、西北视角用于核对整体分区。南立面大门仍待核对。

性能与最终资产指纹见[本批汇总](model-checks/refinement/s2-civil-platform-summary.json)。

同系统 S0 对照下，精细档三次均为 60 FPS，流畅档三次均为 28 FPS；帧率变化分别为 0% 和 −6.67%，三角形增加 4.41% / 10.82%，绘制调用增加 1.28% / 13.69%，均在既定预算内。三次 LOD 往返无错误；27 次 CPU 快照在计时窗口未记录到超过 2% 阈值的 Python/Blender 计算。

## 接续工作

1. 实验大厅：确认南侧构件大门、东西端开口、蓝顶排水坡度和女儿墙，补充入口与现有道路的连续连接。
2. 北综合楼：继续核对主要立面的窗墙比例、白色外框与内侧裸露墙面，再处理屋顶附房、北侧人员入口；不将现有通用窗列计为已校准细节。
3. 低实验区与弧形门厅：核对真实楼层、用途对应、交接细部及屋顶，不把分部估算当作实测。
4. 旧大厅：继续核对独立历史占地与存废时间，不根据拆除采购范围推断已拆除，不另加未经定位的矩形模型。

当前共 22 个校准对象：土木学院 1 栋通过首轮整栋校准，其余 21 个仍为部分校准。平台本批只完成体量与局部窗带工作包，完整 S2–S5 和 20–30 栋目标继续保留。开发、提交、推送仅在 `dev`，未经用户允许不合并主分支。
