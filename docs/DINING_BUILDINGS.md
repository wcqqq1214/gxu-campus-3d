# 东苑、碧湖苑餐厅校准

本批对应 S2，新增两条部分校准记录。两栋原先均采用生活建筑默认六层；根据校方资料改为东苑四层、碧湖苑两层。层高仍按 3.3 米估算，入口和完整立面尚未完成核对，不计为两栋完整复原。
