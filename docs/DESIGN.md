# 风格与菜单

界面遵循“让布局自己说话”：优先用分组、间距和控件状态表达关系，不重复解释已明确的操作。展开的菜单直接以地点、图层、光影页签开头，收起与展开高度的图标按钮与页签同排；面板收起后才显示“校园浏览”作为恢复入口。游览区只显示当前站名、站数与操作，不重复展示暂停或进行中的说明。必要的图例、地点资料、错误恢复、署名与手势帮助保留；图标按钮保留可访问名称与提示，手机点击区域至少 44px。

采用自然配色的三维建筑表现：浅米色石材、白色檐架、蓝绿色玻璃，搭配乔木、棕榈、道路绿带和湖塘。尺寸保持米制比例，没有将建筑、道路宽度或高程艺术性放大。清淡天空与有方向性的自然光照服务于模型阅读，夜景与晨昏都是氛围模拟。

界面以深绿 `#1d624d`、米白面板和细线图标构成。页眉名称为“广西大学 校园地图”，项目图标参考[广西大学官方校徽](https://www.gxu.edu.cn/xdgl1/xxbs1.htm)中央的凤凰与星形冠饰，以朱红圆底和米白曲线作简化表达，省去外围文字及装饰；页眉与浏览器图标共用 `public/favicon.svg`。此图为导览项目的简化标识，不是标准校徽。首屏直接进入场景；桌面页眉拆为左上品牌卡片和右上语言菜单、GitHub 图标按钮，三维画面铺满全屏，左侧为地点与详情共用的可收起面板，右侧为相机工具。底部操作说明、边界图例与 OSM 署名使用半透明小卡片，晨昏夜景下均可阅读。切换到夜景时，面板、标注、工具栏、弹窗和位置小图随之换为深色主题（`:root[data-theme='night']` 重新定义颜色 token），其他光景保持米白主题。手机使用一个底部面板容纳地点、详情和游览。镜头按建筑包围盒及面板实际占用空间自动构图。

菜单采用“地点 / 图层 / 光影”三个入口。页签以凤凰朱红细下划线标识选中状态。桌面端未开始游览时“开始游览”为描边按钮，避免压过正在阅读的地点；游览进行中改为深绿实底。地点列表仅保留编号、地点名称与进入箭头，采用紧凑单行布局，不添加短介绍。项目总体来源与估算边界记录在仓库的数据说明中，逐项依据保留在数据中。从详情返回时固定进入地点列表，并恢复列表位置和键盘焦点；清空搜索后焦点保留在输入框。搜索时先列出匹配的精选地点，再列出“其他建筑”（最多 40 条，其余提示补全名称），无结果时可清空搜索；资料加载失败单独提示并提供重试。

普通建筑导航按实体 ID 排除待核实的冲突轮廓及内部建模对象：`way/759337787` 与精选汇学堂的位置不一致，暂不参与搜索、拾取与选中恢复；“君武文化艺术教育中心”的中英文别名统一指向精选汇学堂。北校园教学组团的七个内部描述也不作为导航地点，模型和原始名称均保留。普通建筑按匹配程度、显示名称和稳定 ID 排序，不使用建模分区 `zone` 判断真实校区。结果与详情用最近精选地标、八方向和约十米精度的直线距离辅助区分同名楼；距离按地图中心坐标估算，不代表步行路线。未核实的名称不擅自改字或补全。

精选地标包含“留学生公寓”和文体分类中的“时光之门”；搜索“留学生”“时空之门”或“图书馆北广场”可定位。运动场仅保留三维场景与图层显示，不提供额外导航标注。第十教学楼为第 19 处，归入教学分类，支持“十教”“10教”“多媒体教学楼”别名及入口近景。荟萃楼为第20处，归入生活分类。游览站数从目录动态读取。

鼠标左键旋转、右键平移、滚轮缩放。触屏使用单指旋转、双指平移和缩放。焦点位于画面时，方向键平移，`+` / `-` 缩放，`Home` 复位。所有菜单可用键盘聚焦。开启系统“减少动态效果”时，镜头直接到达目的地，不播放镜头过渡，环绕按钮禁用；游览需要用户主动开始。手动操作会暂停环绕和游览。搜索、打开操作说明/工具/分享弹窗，以及网页转入后台时，也暂停游览与环绕；关闭弹窗或返回网页后由用户主动继续。

近景最多同时加载两项，优先当前地标，其次邻近道路桥梁与普通建筑区块。首屏加载在画面上方提示；首屏完成后的近景传输属于后台工作，超过 600 毫秒仍未完成时，才在可见画面底部居中显示一枚小进度胶囊，尚无字节时不显示 0%。临时错误最多尝试三次；持续失败时保留已经显示的场景，并出现“重试”。移开镜头后取消多余请求并卸载远处区块，恢复基础模型；最多保留一处最近地标缓存。桌面近景几何缓存预算 64 MiB、窄屏 32 MiB，当前选中地标必须保留，单体超预算时单独加载。该预算是几何缓冲区估算，不是浏览器或 GPU 总内存。WebGL 2 初始化失败时显示开启硬件加速或更换浏览器的提示。建筑资料仍可从仓库访问。

植被采用远近两套模板：首屏和流畅档使用轻量模板，精细档靠近时按需加载圆润树冠及连续棕榈叶，按空间组与相机距离切换。近景模板使用同一两任务队列，优先级低于建筑。普通建筑的轻微材质差异、入口铺装以及植物配色为表现性推定，不代表新增实测资料。

农院路是公共道路，通过围栏和上下分层交通体现与校园的分隔。三座主要桥梁加入精选目录，七座有 OSM 位置依据的湖上桥梁仅展示模型。桥体、道路、名称标注和拾取统一跟随“道路与桥梁”图层；关闭校园建筑不会隐藏桥梁。

六教提供南门、北门独立近景，东西侧门可通过全貌、俯视和环绕观察。

“校园边界”图层默认开启：白色细线标识学校大致范围，保留公共农院路的分隔。位置小图同步显示，导出 PNG 保留边界图例。周边建筑图层仍控制周边建筑，道路与桥梁图层控制规整后的路面。

手机地图页脚仅保留 OSM 署名，操作说明通过“更多”打开，边界说明保留在“图层”。宽屏触摸设备的帮助入口只显示“操作说明”，不提示滚轮操作。手机默认列表收紧标题、页签和搜索区间距，保持原有面板高度与 44px 触摸目标；未搜索时地点总数仅向辅助技术提供，搜索时正常显示结果数量。英文桌面方向与近景按钮使用两列布局，避免 entrance 等单词被拆开；手机仍使用原有横向滚动栏。

## 建模依据与视觉规范

项目名称统一为“广西大学 校园地图”；界面使用“地点 / 游览 / 建模依据”。地点详情仅展示简介、观察视角和分享操作，不显示建模依据徽章或展开内容。建模信息保留在数据中，项目总体来源见 `public/data/sources.json` 与 [数据说明](DATA.md)。

目录共教学 6、文体 5、校门 4、路桥 3、生活 2。编号保持原游览顺序，与地图标注一致；分组不重新编号。列表和标注在悬停或键盘聚焦时相互高亮，不移动镜头。

`modelingBasis` 记录照片建模、类型估算、外观推定三种依据类型，并非测量精度等级；照片建模仍可能包含未见立面和尺寸的推定。当前第二教学楼为类型估算，新东门、博萃桥、荟贤桥为外观推定，其余精选地点为照片建模。该字段保留为数据元信息，不在地点详情显示。

标题使用随仓库分发的 Noto Serif SC 子集（`app/fonts/gxu-serif.woff2`，由 `scripts/build_serif_font.py` 按地点、建筑名称和界面文案生成），保证 Windows 与 macOS 显示一致，缺字回落系统宋体；正文、站号与指北针使用统一无衬线字体栈，数字采用等宽数字特性。深绿收敛为 `--primary`，凤凰朱红 `--phoenix` 用于选中标注、页签下划线与游览进度。标注底部小三角指示落点。校外地形和道路按现有校园边界遮罩降低饱和度并提亮；仅影响渲染材质，不更改地理范围与模型几何。

减少动态效果时隐藏动画进度条，保留当前站名和站数；环绕继续禁用。工具栏提示只展示已支持的快捷键，并注明需要聚焦三维画面。

光照以半球光 0.6–0.78 配合方向阳光区分受光与背光面，晨光偏冷、黄昏低角度偏暖，夜景独立降低环境反射与曝光。手动精细档按需加载 Three.js SAO，以半分辨率、7 次采样与小范围深度模糊补充墙根接触阴影；自动、流畅档不加载后处理，不分配其渲染目标。均衡级暂保留无阴影策略，集显实机证明预算足够前不启用 1024 阴影。

天空由本地 256×128 程序渐变生成，天顶淡蓝、地平线暖亮，与环境反射共用纹理。四个预设分别采用冷灰蓝晨空、淡蓝日空、暖杏色暮空、深蓝夜空。雾的基础范围从 2700 米（夜间 2500 米）开始，在 5800–7800 米范围内融入地平线；当相机距观察目标超过 4000 米时，起止距离同步增加超出的距离，保持雾带宽度，避免手机全景为适应狭窄画幅而拉远镜头后模型被完全遮蔽。近景与常用桌面取景保持原有雾效，截图与后处理使用同一范围。外围地面保持原有边界降饱和遮罩，不修改地形高程或轮廓。

普通建筑按宿舍（暖石色）、教学（微冷灰）、行政实验（中性灰米）、其余（浅砂色）四组附加细微立面色偏，屋顶在浅灰、浅米、冷灰三组间稳定变化。这是按数据类别与名称进行的**表现性推定**，不是对普通建筑立面的实测（当前数据中校内非地标建筑为 433 栋）。以顶点颜色保留区块合批，不增加绘制调用；精选地标的照片建模材质不参与此配色。草地偏暖黄绿，保留已有自制 128×128 纹理的轻微明度变化；铺装略亮，水面更深且偏青。材质不使用校方照片。

树木在现有实例与树位上，以坐标固定种子赋予冠幅 ±25%、高度 ±20% 和三组低饱和绿的明度变化；朝向沿用坐标种子，远近模板使用相同变换。刷新、重排、切档不会重新抽样，不增加树数、三角形或绘制调用。树位与地面高程保持不变。

夜景按玻璃几何的连通窗片／连续楼层单元，以世界坐标固定抽样约 47% 点亮，其他窗户不发光；不更改窗户几何或将整片玻璃统一染黄。主路灯点从现有路缘顶点采样，约 42 米网格一盏，以一组 Points 表现，无真实点光源，跟随道路图层；灯位属于氛围推定。地面与植被夜间降低反射率，返回日景恢复原色，时光之门原有发光保留。手动精细夜景增加半分辨率、阈值 1.35、强度 0.14 的轻量泛光，日间关闭；流畅和自动均不运行后处理。低角度阳光下对草地共点法线作平滑，消除 DEM 网格面片色阶，顶点位置及高程不变。

页面由光影预设同步 `document.documentElement.dataset.theme`，夜景样式通过 `:root[data-theme='night']` 生效；场景直接同步标注容器的 `data-light`。调试指标通过 `onMetrics` 回调进入页面状态。

地标标注优先使用可选 `labelAnchor`（东、北、高程，单位米）；默认取实际模型顶部 30% 主体包围盒的水平中心，并高于模型顶面 0.6 米，剔除低处入口铺装造成的偏移。基础模型、近景加载及卸载后重新核对锚点；无模型时回退到 footprint bounds 中心。全貌构图将标注上方余量纳入取景，避免低矮校门的标注被画面顶部裁掉；不改地点地理中心。

首屏先绘制基础校园，再利用空闲时段细化基础模型的顶点配色与草地法线；资源下载量不变，后处理仍不进入自动首屏。低视角天空将暖色薄雾集中在地平线上方约 20°，让常用近景也能读出天顶淡蓝与暖亮地平线的层次。

自动画质对持续环绕或镜头动画中的极低帧率保留真实帧间隔，即使每个采样窗只有 1 帧也可降档；静止画面的稀疏重绘仍不触发降档，避免把空闲误认为性能不足。

流畅级在原有像素比上再乘 0.9（内部渲染宽高各减 10%、像素总量约减 19%），为渐变天空与材质层次留出预算；1920×1080、DPR=1 时内部渲染为 1728×972，界面仍按原视口显示。自动降到流畅级时采用相同预算。
