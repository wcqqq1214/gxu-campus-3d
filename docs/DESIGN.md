# 风格与菜单

采用自然配色的三维建筑表现：浅米色石材、白色檐架、蓝绿色玻璃，搭配乔木、棕榈、道路绿带和湖塘。尺寸保持米制比例，没有将建筑、道路宽度或高程艺术性放大。绿灰天空与柔和光照服务于模型阅读，夜景与晨昏都是氛围模拟。

界面以深绿 `#1d624d`、米白面板和细线图标构成。页眉名称为“广西大学 校园地图”，项目图标参考[广西大学官方校徽](https://www.gxu.edu.cn/xdgl1/xxbs1.htm)中央的凤凰与星形冠饰，以朱红圆底和米白曲线作简化表达，省去外围文字及装饰；页眉与浏览器图标共用 `public/favicon.svg`。此图为导览项目的简化标识，不是标准校徽。首屏直接进入场景；桌面左侧使用地点与详情共用的可收起面板，右侧为相机工具。手机使用一个底部面板容纳地点、详情和游览。镜头按建筑包围盒及面板实际占用空间自动构图。

菜单采用“地点 / 图层 / 光影”三个入口。页签以凤凰朱红细下划线标识选中状态，深绿实底突出“开始游览”。地点列表仅保留编号、地点名称与进入箭头，采用紧凑单行布局，不添加短介绍。详细来源与估算边界仍留在详情中。 从详情返回时固定进入地点列表，并恢复列表位置和键盘焦点；清空搜索后焦点保留在输入框。搜索时平铺显示匹配地点，无结果时可清空搜索；资料加载失败单独提示并提供重试。

| 菜单 | 操作与结果 |
| --- | --- |
| 地点 | 按教学、文体、校门、路桥和生活分组，支持“六教”“二教”“新东园门”“农院路”等别名；列表、可点击建筑和地标标注共用精选目录，普通建筑不进入导航。详情展示简介、位置来源、地图编辑时间与建模依据。 |
| 地图图层 | 8 项开关分别控制校内建筑、植被、道路与桥梁、湖塘、运动场、周边建筑、地点名称、校园边界。草地属于基础地形。 |
| 光影 | 晨光、日间、黄昏、夜景以图书馆同一视角预览，改变天空、太阳方向和窗户亮度；画质选项默认折叠。自动档按窄屏、省流设置及活动帧率调整分辨率；精细档开启完整植被、阴影和分区近景；流畅档降低植被数量、像素比，并关闭阴影和普通建筑及道路区块近景。独立地标仍可打开。 |
| 视角控制 | 放大、缩小、俯视、倾斜鸟瞰、正北朝向、全景复位及全屏；左上角凤凰图标也可复位。地点详情共用一条横向视角栏，依次提供全貌、俯视、环绕、正面、背面和近景；手机简要与展开状态保留同一组控件。图书馆分别提供南北门，三座精选桥梁提供桥下近景，时光之门提供雕塑近景。 |
| 校园游览 | 游览入口常驻面板底部，20 站每站约 8.5 秒，朱红进度条提示自动换站；开始、暂停、继续、上一站、下一站、结束；拖动、滚轮、键盘或主动点选其他地标暂停游览。 |
| 导出画面 | 下载当前三维视图 PNG，底部包含项目名称及 OSM 署名；不包含菜单。 |
| 位置与分享 | 底部小图按真实建筑轮廓显示位置，棕线区分公共农院路，指北工具随镜头旋转。分享菜单提供复制当前地点、视角和光照的快照链接及下载画面；换屏时保持观察范围，手动操作后可复制新的快照。 |
| 项目说明 | 介绍覆盖、统计、数据年份、精度、操作、许可及 GitHub 入口。 |

精选地标包含“留学生公寓”和文体分类中的“时光之门”；搜索“留学生”“时空之门”或“图书馆北广场”可定位。运动场仅保留三维场景与图层显示，不提供额外导航标注。第十教学楼为第 19 处，归入教学分类，支持“十教”“10教”“多媒体教学楼”别名及入口近景。荟萃楼为第20处，归入生活分类。游览站数从目录动态读取。

鼠标左键旋转、右键平移、滚轮缩放。触屏使用单指旋转、双指平移和缩放。焦点位于画面时，方向键平移，`+` / `-` 缩放，`Home` 复位。所有菜单可用键盘聚焦。开启系统“减少动态效果”时，镜头直接到达目的地，不播放镜头过渡，环绕按钮禁用；游览需要用户主动开始。手动操作会暂停环绕和游览。搜索、打开项目说明/操作说明/工具/分享弹窗，以及网页转入后台时，也暂停游览与环绕；关闭弹窗或返回网页后由用户主动继续。

近景最多同时加载两项，优先当前地标，其次邻近道路桥梁与普通建筑区块。展示传输进度，临时错误最多尝试三次；持续失败时保留已经显示的场景，并出现“重试”。移开镜头后取消多余请求并卸载远处区块，恢复基础模型；最多保留一处最近地标缓存。桌面近景几何缓存预算 64 MiB、窄屏 32 MiB，当前选中地标必须保留，单体超预算时单独加载。该预算是几何缓冲区估算，不是浏览器或 GPU 总内存。WebGL 2 初始化失败时显示开启硬件加速或更换浏览器的提示。建筑资料仍可从仓库访问。

植被采用远近两套模板：首屏和流畅档使用轻量模板，精细档靠近时按需加载圆润树冠及连续棕榈叶，按空间组与相机距离切换。近景模板使用同一两任务队列，优先级低于建筑。普通建筑的轻微材质差异、入口铺装以及植物配色为表现性推定，不代表新增实测资料。

农院路是公共道路，通过围栏和上下分层交通体现与校园的分隔。三座主要桥梁加入精选目录，七座有 OSM 位置依据的湖上桥梁仅展示模型。桥体、道路、名称标注和拾取统一跟随“道路与桥梁”图层；关闭校园建筑不会隐藏桥梁。

六教提供南门、北门独立近景，东西侧门可通过全貌、俯视和环绕观察。

“校园边界”图层默认开启：白色细线标识学校大致范围，保留公共农院路的分隔。位置小图同步显示，导出 PNG 保留边界图例。周边建筑图层仍控制周边建筑，道路与桥梁图层控制规整后的路面。

## 建模依据与视觉规范

项目名称统一为“广西大学 校园地图”；界面使用“地点 / 游览 / 建模依据”。“高度依据”和“位置来源”是建模依据中的具体字段，不作为这一入口的别名。简介仅描述地点特点，建模推定与精度说明留在依据中。

目录共教学 6、文体 5、校门 4、路桥 3、生活 2。编号保持原游览顺序，与地图标注一致；分组不重新编号。列表和标注在悬停或键盘聚焦时相互高亮，不移动镜头。

`modelingBasis` 记录照片建模、类型估算、外观推定三种依据类型，并非测量精度等级；照片建模仍可能包含未见立面和尺寸的推定。当前第二教学楼为类型估算，新东门、博萃桥、荟贤桥为外观推定，其余精选地点为照片建模。点击徽章展开完整依据。

标题保留宋体，正文、站号与指北针使用统一无衬线字体栈，数字采用等宽数字特性。深绿收敛为 `--primary`，凤凰朱红 `--phoenix` 用于选中标注、页签下划线与游览进度。标注底部小三角指示落点。校外地形和道路按现有校园边界遮罩降低饱和度并提亮；仅影响渲染材质，不更改地理范围与模型几何。

减少动态效果时隐藏动画进度条，保留当前站名和站数；环绕继续禁用。工具栏提示只展示已支持的快捷键，并注明需要聚焦三维画面。
