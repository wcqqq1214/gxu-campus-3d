# 界面与交互

本页维护界面行为与视觉约束。来源、覆盖和估算边界见 [DATA.md](DATA.md)，模型构建及浏览器检查见 [MODELING.md](MODELING.md)。

## 布局与视觉

遵循 [AGENTS.md](../AGENTS.md) 的文案原则：用分组、间距和控件状态表达关系，保留必要资料、图例、署名、错误恢复与手势帮助。图标按钮有可访问名称和提示，移动端有效点击区域至少 44px；中英文及桌面、窄屏一起验证。

页面名为“广西大学 校园地图”，首屏直接进入三维场景。桌面左上为品牌，右上为语言和 GitHub 入口，左侧共用地点与详情面板，右侧为相机工具；手机用底部面板容纳地点、详情和游览。展开面板以“地点 / 图层 / 光影”页签开头，收起后显示“校园浏览”恢复入口；镜头按模型范围和面板实际占位构图。

颜色由 [globals.css](../app/globals.css) 统一维护：sage 中性色、jade 绿色操作强调、red 当前地点强调。页签使用绿色下划线；未开始游览的按钮为浅绿色背景，进行中的主按钮使用绿色实底。夜景将页面、标注、小图和弹窗同步切为深色；页面在根节点设置 `data-theme` 并切换 `.dark-theme`，后者驱动 Radix 深色调色板。

项目图标参考[广西大学官方校徽](https://www.gxu.edu.cn/xdgl1/xxbs1.htm)中央凤凰与星冠，使用朱红圆底与米白曲线，页眉和浏览器共用 `public/favicon.svg`；这是导览项目简化标识，不是标准校徽。标题使用随仓库分发的 Noto Serif SC 子集 `app/fonts/gxu-serif.woff2`，由 `scripts/build_serif_font.py` 随文案和名称更新，缺字回落系统宋体；正文使用无衬线字体，数字等宽。

## 浏览与导航

| 入口 | 行为 |
| --- | --- |
| 地点 | 列表、标注、游览共用精选目录，按教学、文体、校门、路桥、生活分组，分组不改变编号。单行只展示编号、名称与箭头；悬停或键盘聚焦同步高亮标注，不移动镜头。详情展示简介、观察视角和分享，建模依据留在数据与文档中。 |
| 搜索 | 先列精选匹配项，再列最多40条有名称的校内普通建筑，超出时提示补全名称。支持中英文和别名，排除占位名称、校外建筑与已属精选的建筑。普通楼仅从搜索结果选中，以金色轮廓线突出，提供位置、类别、估算层数/高度、全貌、俯视及分享，不参与游览或地图悬停拾取。 |
| 图层 | 控制校内建筑、植被、道路与桥梁、湖塘、运动场、周边建筑、地点名称和校园边界；草地属于基础地形。桥体、名称与拾取跟随道路图层，不随建筑隐藏；运动场不另设导航标注。 |
| 光影 | 晨光、日间、黄昏、夜景使用同一图书馆视角预览；画质选项默认折叠，具体行为见下节。 |
| 视角 | 支持缩放、俯视、倾斜鸟瞰、正北、全景和全屏，品牌图标也可复位。地点共用视角控件，按可用视点提供全貌、俯视、环绕、正背面或入口近景；图书馆与六教可分别看南北门，精选桥梁有桥下近景。 |
| 游览 | 入口常驻面板底部，站数与顺序来自目录。提供开始、暂停、继续、前后站和结束，进度条提示换站；只展示当前站名、站数与操作。 |
| 位置与分享 | 小图使用真实建筑轮廓，棕线区分公共农院路；指北工具随相机旋转。快照链接保存地点、视角和光照，换屏保持观察范围；导出 PNG 包含项目名、OSM 署名和边界图例，不包含菜单。 |

从详情返回固定进入地点列表，恢复滚动位置和键盘焦点；清空搜索仍聚焦输入框。无结果提供清空，资料加载失败独立提示并可重试。

普通建筑导航规则由 [navigation.ts](../lib/campus/navigation.ts) 管理：按匹配度、显示名称和稳定 ID 排序，不把建模分区 `zone` 当真实校区；用最近地标、八方向和约十米精度的直线距离区分同名楼，距离不是步行路线。冲突轮廓 `way/759337787` 不参与搜索、拾取或选中恢复，“君武文化艺术教育中心”别名统一指向精选汇学堂；北校园七个内部建模描述也不作为地点，原始名称与模型保留。未核实的名称不擅自改字补全。

农院路作为公共道路，由围栏、分层交通和校园边界共同表达分隔。边界默认开启，仅表示大致范围，小图与导出图同步。手机页脚仅保留 OSM 署名，边界说明在“图层”，操作说明从“更多”打开；宽屏触摸设备不提示滚轮操作。未搜索时地点总数仅向辅助技术提供，搜索时显示结果数。英文桌面方向与近景按钮使用两列，手机保持横向滚动，面板简要/展开状态共用控件。

## 输入与动态效果

鼠标左键旋转、右键平移、滚轮缩放；触屏单指旋转、双指平移与缩放。三维画面获得焦点时，方向键平移，`+` / `-` 缩放，`Home` 复位；工具提示仅列已支持的快捷键并说明焦点条件，菜单可键盘操作。

手动操作、主动选择其他地点、搜索、打开帮助/工具/分享弹窗或转入后台均暂停游览与环绕，返回后由用户继续。系统“减少动态效果”开启时，镜头直接到达目的地，环绕禁用，隐藏动画进度条但保留站名与站数；游览始终由用户主动开始。

## 加载、画质与恢复

首屏先显示基础校园，再于空闲时段细化顶点配色与草地法线。近景共用两任务队列，优先当前地标，其次邻近道路和普通建筑，球场与植物靠后。首屏有加载提示；后台近景传输超过600毫秒才显示底部进度胶囊，未获字节时不显示0%。临时错误最多尝试三次，持续失败保留已有场景并提供重试。

移开镜头后取消多余请求、卸载远处区块并恢复基础模型，最多缓存一处最近地标；当前选中项必须保留，单体超预算时单独加载。几何缓存预算随画质与窄屏调整，不代表浏览器或 GPU 总内存。队列、重试与预算的实现分别见 [streaming.ts](../lib/campus/streaming.ts) 和 [quality.ts](../lib/campus/quality.ts)。WebGL 2 初始化失败时提示硬件加速或更换浏览器，建筑资料仍可从仓库访问。

| 画质 | 约束 |
| --- | --- |
| 自动 | 从均衡级启动，结合窄屏、省流及活动帧率调整；静止稀疏重绘不触发降档，持续运动极低帧率仍能降档。均衡级保持无阴影，自动档不加载后处理。 |
| 精细 | 完整植被、阴影与分区近景；手动选择后才按需加载半分辨率接触遮蔽，夜间附加轻量泛光。 |
| 流畅 | 降低植被密度与内部渲染分辨率，关闭阴影、普通建筑和道路区块近景；独立地标仍可打开，球场保留基础档。自动降至此级使用同一预算。 |

植被远近模板按空间组和距离切换，沿用相同树位、朝向与固定种子变换。篮球近景在道路和建筑之后加载，共用内存预算，失败或切到流畅档时回退基础球场。

## 场景表现约束

建筑、道路和高程保持米制比例，不艺术性放大。自然光、天空、晨昏和夜景用于阅读模型，均不是现场照明测量；模型使用自制纹理，不将校方照片作为材质。

| 实现入口（`lib/campus/`） | 保留的行为 |
| --- | --- |
| `palette.ts`、`context-style.ts` | 普通建筑按类别施加稳定色差，精选照片建模材质不参与；外围地面和道路降饱和提亮，仅改变渲染，不改地理范围或几何。普通建筑配色属于表现性推定。 |
| `vegetation.ts` | 按坐标固定种子调整冠幅、高度与配色，刷新、重排、切档不重新抽样；不增加树数或绘制调用，远近模板变换一致。 |
| `lighting.ts`、`sky.ts`、`postprocessing.ts` | 本地渐变天空与环境反射共用纹理；全景相机拉远时雾带同步后移，避免窄屏全景被遮蔽，截图和后处理共用雾范围。细部光照参数在实现中维护。 |
| `night.ts` | 按世界坐标稳定抽样点亮部分玻璃单元，不整片染黄；主路灯用 Points 模拟，跟随道路图层，无真实点光源。灯位为氛围推定，日景恢复原色，时光之门原有发光保留。 |
| `shadow-frustum.ts`、`scene.ts` | 仅环绕时复用阴影图；平移、缩放、光照、模型/图层/植被 LOD、画质及上下文恢复触发更新。新增移动投影物或改几何须设置 `renderer.shadowMap.needsUpdate`，不能只请求重绘；`shadowUpdates` 指标可核验。 |
| `labels.ts`、`camera.ts` | 标注优先采用 `labelAnchor`（东、北、高程，米），否则取模型上部主体中心，未加载时回退轮廓中心。近景加载/卸载后重算，全貌构图纳入标注余量，避免低矮门楼文字被裁切，不改地点地理中心。 |
