# 风格与菜单

采用自然配色的三维建筑表现：浅米色石材、白色檐架、蓝绿色玻璃，搭配乔木、棕榈、道路绿带和湖塘。尺寸保持米制比例，没有将建筑、道路宽度或高程艺术性放大。绿灰天空与柔和光照服务于模型阅读，夜景与晨昏都是氛围模拟。

界面以深绿 `#315f4e`、米白面板和细线图标构成。首屏直接进入场景；桌面左侧为探索菜单，右侧为相机工具及建筑详情。窄屏下为可收起的底部面板。

| 菜单 | 操作与结果 |
| --- | --- |
| 校园探索 | 搜索名称或 OSM ID；教学、生活、文体、精选地标、全部筛选；点选列表、地图建筑或地标标注进行定位。详情展示简介、位置来源、地图编辑时间与复原依据。 |
| 地图图层 | 7 项开关分别控制校内建筑、植被、道路、湖塘、运动场、周边建筑、地点名称。草地属于基础地形。 |
| 环境设置 | 晨光、日间、黄昏、夜景改变天空、太阳方向和窗户亮度。自动档按窄屏、省流设置及活动帧率调整分辨率；精细档开启完整植被、阴影和分区近景；流畅档降低植被数量、像素比，并关闭阴影和普通建筑近景。独立地标仍可打开。 |
| 视角控制 | 放大、缩小、俯视、倾斜鸟瞰、正北朝向、全景复位及全屏；左上角“西”也可复位。 |
| 校园巡游 | 10 站每站约 8.5 秒；开始、暂停、继续、上一站、下一站；拖动、滚轮、键盘或主动点选其他建筑暂停巡游。 |
| 导出画面 | 下载当前三维视图 PNG，底部包含项目名称及 OSM 署名；不包含菜单。 |
| 项目说明 | 介绍覆盖、统计、数据年份、精度、操作、许可及 GitHub 入口。 |

输入“田径场”可直接定位东、西运动场及西场主席台，也可从“文体”分类选择。场地详情列出近期照片、OSM 编辑日期及估算尺寸。两处场地标注随“运动场地”图层开关；它们不增加十站建筑巡游的站点数。

鼠标左键旋转、右键平移、滚轮缩放。触屏使用单指旋转、双指平移和缩放。焦点位于画面时，方向键平移，`+` / `-` 缩放，`Home` 复位。所有菜单可用键盘聚焦。开启系统“减少动态效果”时，镜头直接到达目的地，不播放镜头过渡；巡游需要用户主动开始。

资源加载失败时保留已经显示的场景，并出现“重试”；WebGL 2 初始化失败时显示开启硬件加速或更换浏览器的提示。建筑资料仍可从仓库访问。
