# 界面与交互

本页说明网页端的界面布局、交互逻辑与渲染约束。数据来源与估算边界见 [DATA.md](DATA.md)，构建与回归检查见 [MODELING.md](MODELING.md)。

## 布局与视觉

界面文案、无障碍标签与移动端 44px 触控区规范遵循 [AGENTS.md](../AGENTS.md)，改版须同步验证中英文及桌面、窄屏布局。

页面标题为“广西大学 校园地图”，打开后直接进入三维场景：
- **桌面端**：左上角为品牌标题，右上角为语言切换与 GitHub 入口；左侧面板共用地点列表与详情页，右侧停靠视角工具栏。
- **移动端**：地点列表、详情与游览控件收纳在底部抽屉中。展开面板顶部显示“地点 / 图层 / 光影”页签，收起后显示“校园浏览”入口；相机构图会自动避开当前面板占据的区域。

色彩体系维护在 [globals.css](../app/globals.css) 中，以 `sage` 为中性灰绿底色，`jade` 为交互强调色，`red` 标识当前选中地点（页签用绿色下划线，游览主按钮在未开始时为浅绿底、进行中为绿色实底）。切换到“夜晚”模式时，根节点会设置 `data-theme` 并启用 `.dark-theme`（驱动 Radix 深色调色板），使面板、标注、小地图与弹窗同步进入深色外观。

项目图标 `public/favicon.svg` 参考[广西大学官方校徽](https://www.gxu.edu.cn/xdgl1/xxbs1.htm)中央的凤凰与星冠简化而成，仅作导览标识使用。界面标题使用随仓库分发的 Noto Serif SC 子集（`app/fonts/gxu-serif.woff2`，由 `scripts/build_serif_font.py` 随文案和地名更新），缺字回退系统宋体；正文用无衬线字体，数字等宽对齐。

## 浏览与导航

| 模块 | 交互说明 |
| --- | --- |
| 地点 | 列表、地图标注与自动游览共用精选目录，按教学、文体、校门、路桥、生活分组（分组不影响编号）。单行只展示编号、名称与箭头；悬停或聚焦同步高亮对应标注，不移动镜头。详情展示简介、视角控件与分享入口。 |
| 搜索 | 同时检索精选地标与最多 40 条有名称的校内普通建筑（超出时提示输入更完整的名称）；支持中英文、院系简称、合用单位、食堂供餐点与学生宿舍别名，排除占位编号、校外建筑及已属精选的楼栋。普通建筑仅从搜索选中，以金色轮廓线突出，展示方位距离、类别、估算层高以及全貌、俯视与分享，不参与游览或地图悬停拾取。 |
| 图层 | 可开关校园建筑、树木、道路与桥梁、水面、运动场地、周边建筑、地点名称与校园边界（草地属于基础地形）。桥梁的模型、名称与拾取跟随“道路与桥梁”图层，不随建筑隐藏；运动场地不设地图标注。 |
| 光影 | 提供清晨、白天、黄昏、夜晚四种光照（`public/images/presets/{morning,day,evening,night}.jpg` 均取自“图书馆 → 全貌”实景渲染，隐藏标注，1280×720 视口下以 `x=465, y=270` 裁剪 `640×360`，光照或周边模型大改时同步重截）；渲染画质选项置于面板下方。 |
| 视角 | 工具栏支持缩放、俯视、鸟瞰、朝向正北、回到全景和全屏（左上角图标也可复位全景）。地点详情共用视角控件，按地点提供全貌、俯视、环绕及正面/背面或入口近景；图书馆与六教可分别看南北门，跨农院路桥梁提供桥下近景。 |
| 游览 | 常驻面板底部，站数与顺序来自目录；支持开始、暂停、继续、上一站、下一站与结束，并用进度条提示换站。 |
| 位置与分享 | 小地图按真实建筑轮廓绘制，棕线区分公共道路农院路，指北箭头随镜头旋转。分享链接编码当前地点、相机与光照，换屏打开保持相同观察范围；导出 PNG 附带标题、OSM 署名和边界图例，不含界面控件。 |

从详情返回固定回到地点列表，并恢复滚动位置与键盘焦点；清空搜索后焦点留在输入框，无结果提供清空按钮，加载失败独立提示并可重试。

普通建筑与院系检索规则维护在 [navigation.ts](../lib/campus/navigation.ts) 和 [college-venues.ts](../lib/campus/college-venues.ts) 中：
- 按匹配度（精确 > 前缀 > 子串）、主副楼优先级（学院主楼优先于 `secondary` 附楼）、当前语言显示名称与稳定 ID 排序，不把内部建模分区 `zone` 当作校区。
- 当搜索词命中学院合用楼（`collegeVenues`）且匹配层级优于精选地标（或同级匹配但为主楼）时，“其他建筑”分组排在“精选地点”之前（`buildingsFirst`）。兼作学院或场馆的精选地标（如荟萃楼、综合实验大楼、留学生公寓、综合体育馆）在浏览列表显示原名，搜索命中学院词条时切换显示对应的学院或合用楼名称（`destinationName`）。
- 同名或普通建筑以“最近地标 + 八方位 + 十米取整直线距离”标示相对位置，该距离不代表步行路线。
- `way/759337787` 按核实名称显示为“君武馆”，原“君武文化艺术教育中心”别名统一指向汇学堂；北校园 7 个内部建模分组占位描述（`north-campus/*`）不作为搜索目标或分享恢复对象（保留原名与模型），未核实名称不臆测补全。

农院路通过围栏、下穿分层与默认开启的校园大致边界共同表达分隔。移动端页脚仅保留 OSM 署名（边界图例在“图层”，操作说明在“更多工具”）；带触摸屏的宽屏设备不提示鼠标滚轮操作。未搜索时地点总数仅向屏幕阅读器播报，搜索时在界面显示结果数；英文模式下，桌面端方位与近景按钮采用两列布局，移动端维持横向滚动，面板简要与展开状态共用同一套控件。

## 输入与动态效果

- **鼠标与触控板**：左键拖动旋转，右键拖动平移，滚轮缩放。
- **触屏**：单指旋转，双指平移与捏合缩放。
- **键盘**：画布获得焦点时，方向键平移，`+` / `-` 缩放，`Home` 回到全景（悬停提示会注明焦点条件）；菜单与弹窗均支持键盘操作。

手动拖动画面、切换地点、聚焦搜索框、打开弹窗或页面切入后台时，自动游览与环绕都会暂停并等待继续。系统开启“减少动态效果”时，镜头直接跳转到位，禁用自动环绕，隐藏游览动画进度条（保留站名与序号）；游览始终由用户主动开启。

## 加载、画质与恢复

首屏先渲染基础校园，再在空闲时段细化顶点配色与草地法线。近景流式加载共用两个并发队列，优先当前选中地标；若当前选中普通建筑或学生宿舍，则优先为其所属近景块（`chunk-*` 或 `chunk-dorm-*`）预留预算名额，随后加载邻近道路与其余建筑区块，球场与植物靠后。预算核算优先读取实测缓存成本或清单中的 `geometryBytes`（解码几何缓冲区上限）。后台传输超过 600 毫秒才在底部弹出进度胶囊（未获总字节时不显示 `0%`）；临时网络错误最多自动重试三次，持续失败保留已有画面并提供重试。

移开镜头后会取消多余请求、卸载远处区块并恢复基础几何，最多缓存一处最近地标；当前选中项始终保留，单体超常规预算时仍单独加载。缓存预算随画质与窄屏调整，不等同于设备总显存。队列、重试与预算逻辑见 [streaming.ts](../lib/campus/streaming.ts) 和 [quality.ts](../lib/campus/quality.ts)。WebGL 2 初始化失败时提示开启硬件加速或更换浏览器。

| 画质 | 渲染与调度策略 |
| --- | --- |
| 自动 | 从“均衡”档起步，结合窄屏、省流开关与活动帧率动态调整；静止稀疏重绘不触发降档，持续运动极低帧率仍可降档。“均衡”档无实时阴影，“自动”档不加载后处理。 |
| 精细 | 启用完整植被、阴影与分区近景；手动选至此档后按需加载半分辨率接触遮蔽，夜晚附加轻量泛光。 |
| 流畅 | 降低植被密度与内部渲染分辨率（约减少 19% 像素），关闭阴影及普通建筑、道路区块近景；独立地标仍可打开，篮球场保持基础档。自动降级至此时采用同一预算。 |

植被远近模板按空间区与视距切换，沿用同一树位、朝向与固定随机变换；篮球场近景排在道路和建筑之后加载并共用内存预算，加载失败或切到流畅档时回退基础球场。

## 场景表现约束

场景中的建筑、道路与高程保持米制比例，不做艺术性放大；昼夜预设仅用于阅读模型，不模拟真实照度；建筑均采用自制程序纹理，不使用参考照片作贴图。

| 实现模块（`lib/campus/`） | 负责的行为与约束 |
| --- | --- |
| `palette.ts`、`context-style.ts` | 普通建筑按分类施加稳定色差（照片建模地标除外）；校外周边地面与道路降饱和提亮，仅作用于渲染。 |
| `vegetation.ts` | 按坐标固定种子微调冠幅、树高与配色，刷新、重排或切换画质不重新抽样，也不增加树数或绘制调用。 |
| `lighting.ts`、`sky.ts`、`postprocessing.ts` | 本地渐变天空与环境反射共用纹理；全景拉远时雾带同步后移（截图与后处理共用同一雾范围），避免窄屏全景被遮蔽。 |
| `night.ts` | 夜晚按世界坐标稳定抽样点亮部分玻璃窗格（不整片染黄），主干道路灯用 `Points` 模拟并跟随道路图层，无真实点光源；切回白天恢复原色，时光之门保留原有发光。 |
| `shadow-frustum.ts`、`scene.ts` | 仅绕静态地点环绕时复用阴影贴图；平移、缩放、改光照/图层/植被 LOD/画质或上下文恢复均触发更新。新增投影物或改几何须设置 `renderer.shadowMap.needsUpdate`，可通过 `shadowUpdates` 核验。 |
| `labels.ts`、`camera.ts` | 标注取模型上部主体中心（未加载时回退轮廓中心），近景切换后重算；全貌自动构图会为低矮门楼的标注留出顶部余量，不改地理中心。 |
