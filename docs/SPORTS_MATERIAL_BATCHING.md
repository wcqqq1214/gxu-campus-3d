# 跑道纯色分组合批

2026-09-21。土木学院前庭完成后，流畅档绘制调用已达到同系统S0基线的114.83%，接近计划15%的增幅上限。本批先减少现有场地的重复材质提交，为后续建筑细化保留预算；学院楼连接段、附楼屋面及整栋验收仍待完成，后续顺序保持实验大厅 → 新结构大楼。

## 实现与边界

两处跑道节点各有五种纯色铺面材质：跑道交替色、外圈、足球场底色及条带。它们在当前资产中的粗糙度、金属度、双面及其他材质参数相同，只差颜色。运行时将这些颜色写成线性RGB顶点属性，并在各自跑道父节点内合并网格。每处由8个材质网格降为4个，三角形数量不变。

[合批模块](../lib/campus/sports-batching.ts)只处理`sports-east-track`和`sports-west-track`下明确列出的五种铺面材质。材质其余序列化参数、局部变换、阴影、图层和渲染顺序必须匹配；带贴图、透明、已有顶点色、局部分组或绘制范围、骨骼/实例网格等不进入该路径。标线保持原有深度偏移和不投影设置，运动场地的父节点、图层身份及加载机制保持。

合并后的包围体可能让原来分开裁剪的铺面一起参与绘制，因此最终渲染三角形仍需实测，不能只据几何不变宣称所有视角成本不变。新增颜色缓冲合计167,544字节，约163.62 KiB；这是属性数据量，不是实测总显存。旧网格移除后按现有资源释放规则清理，其他节点共享的资源保留。

GLB、Blender源文件、模型清单及生产地理数据均保持`d8a7642`，无需重建模型。代码在模型解码和材质样式应用后运行；日夜切换不修改这五种铺面材质的颜色。TypeScript保持`noEmit`，开启`allowImportingTsExtensions`使模块内部的`.ts`依赖也能由现有Node原生TypeScript测试直接加载。

## 验证

[实际Draco解码对照](model-checks/refinement/s5-track-batching-decoded.json)检查东西跑道共20,158个有向三角形：位置、法线、线性颜色、存在时的UV及其他材质参数按Float32一致。每处减少四个绘制分组；未用自造几何代替实际资产检查。另有三项单元测试覆盖颜色与变换、拒绝不兼容材质、共享资源释放、标线保留和重复调用。

## 复现

```sh
node --experimental-strip-types scripts/check-sports-batching.mjs
npm test
npm run typecheck
npm run lint
npm run build:pages
```

浏览器脚本为`scripts/check-sports-batching-browser.mjs`，接受新的报告阶段名，要求`PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`和修改前/后生产预览地址（默认4312/4300）；已有报告不会覆盖。活动测量继续使用原`check-refinement-browser.mjs`协议及同系统S0基线，不调整预算。
