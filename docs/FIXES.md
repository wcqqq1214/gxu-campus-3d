# 优化修复记录 · 2026-09-11

按项目优化审查逐项修复，每组验证后独立提交，全部完成后统一推送。

## 1. 巡游状态与键盘焦点

- 区分手动、巡游与分享恢复的选中来源。自动换站保留面板模式和收起状态；手动选点同步巡游站点。
- 收起面板后仍可暂停、继续并查看站点进度。
- 主动进入详情聚焦返回按钮；返回恢复原列表项焦点及列表滚动位置。
- 验证：类型、lint、40 项 Node 测试、Pages 生产构建通过。实际浏览器用 Enter 从六教列表进入详情并返回，焦点分别为返回按钮与六教列表项；从第 7 站巡游到第 9 站面板仍收起，紧凑暂停按钮可用。

## 2. 近景资源名额与预算

- 道路与普通建筑分别计算最多三个近景名额，仍与当前地标共享几何预算；地标尚未完成时先限制为一个建筑块。
- 提取实际调度函数，新增当前图书馆资产回归：三条道路不再排挤建筑；预算不足仍限制建筑；前景未就绪保留优先级。
- 验证：类型、5 项流送测试、Pages 构建通过。实际浏览器图书馆同时驻留一个地标、三条道路、三个建筑块，队列清空，近景几何估算 47 MiB，低于桌面 64 MiB 预算。该数值不是总显存。
