# 原环境楼候选：入口外景与层数冲突核对

2026-09-30；S3必需邻楼 `way/759170251`，当前OSM名称“野生动物研究所”，八层、26.4米。校方历史规划图对应位置的“环境学院7F”仍与OSM层数冲突。本批找到具名局部外景及两种电梯层站记录，补充了下一步定位依据，尚不足以更改生产模型。

## 新取得的外景

[动物学院2023年3月23日活动报道](https://dky.gxu.edu.cn/info/1240/1952.htm)记载3月17日先在繁殖所前清扫、随后到环境楼前整理车辆。已在校方网页直接核看全部七张原图，不能把同一篇报道的每张图片都归给环境楼。

| 正文顺序 | 可见内容 | 对模型的约束 |
| --- | --- | --- |
| 1 | 绿化、道路和清扫活动 | 无屋顶或楼体尽端，不能确定总层数 |
| 2 | 整理车辆；后方为浅色贴砖窗墙与棕榈 | 可见局部窗型；最高屋面及两端缺失 |
| 3 | 低矮圆角凸部、绿化与道路 | 环境楼或繁殖所的对应关系尚未建立，不为长条楼添加圆角 |
| 4 | 步道清扫、局部墙角 | 缺少唯一定位锚点 |
| 5 | 题名石上的“环境学院”可辨；后方有浅色方砖墙、窗栏、花池及棕榈 | 新增可靠的历史环境学院外景线索；无法从两层局部推定整栋总层数 |
| 6 | 合影背景有较低通风口带、上方成组窗，照片上缘被截断 | 不把低矮窗带直接解释为地下室，也不据此解决7F/8F差异；楼栋归属仍需独立定位 |
| 7 | 台阶、矩形门柱和单位牌；牌匾可辨环境工程研究中心、清洁生产技术中心等文字 | 可建立入口形制候选，但入口方位、宽度和沿墙位置尚未知 |

其中[题名石原图](https://dky.gxu.edu.cn/__local/8/5D/1C/9C2F595E131F9950A8D073E4E1B_E10ED9E9_13F5F1.png)为690×473像素，[入口原图](https://dky.gxu.edu.cn/__local/A/49/02/7F26C58091A79AD8CDCA51220C7_32C3DC4C_113F26.png)为613×460像素。牌匾说明历史使用关系，不能证明2026年整栋由单一单位使用；正文活动日期亦不等于照片的独立拍摄元数据。

这批照片与[历史规划图的位置推断](NEIGHBOR_EVIDENCE_REVIEW.md)相互补充，但还没有包含“题名入口—楼体尽端—可识别路口”的同框关系。当前107米×18米左右的地图矩形没有门廊定位细节，不能仅因入口照片近似对称，就把门放到现有默认南墙中点。

## 两条室内线索的排除

[后勤基建处2022年10月30日施工检查报道](https://ghjjc.gxu.edu.cn/info/1057/2088.htm)第三张照片的图注明确指向旧环境楼改造。已核看4032×3024原图：为房间内的施工检查，画面只有局部外窗和室内门，无法定位外墙或核对最高楼层。

[生命学院2023年4月24日检查报道](https://lst.gxu.edu.cn/info/1095/3744.htm)记载4月20日检查本科实验教学中心。其1022×766原图同为室内场景，没有可用于建筑轮廓配准的楼体尽端或屋顶。这两张图片不计入整栋外观佐证。

## 电梯记录不能直接解决地上层数

[校方2021年4月9日电梯维保公告](https://www.gxu.edu.cn/info/1364/30846.htm)的表头是“层站”，第23、24行均名为环境楼：一台为9/9，另一台为8/8，启用年份均列2016年8月。已核对完整表头和两行，未把搜索摘要中的数字单独采用。该表另列资源环境与材料学院大楼，不能混用两个名称对应的数字。

| 待判字段 | 当前证据 | 决定 |
| --- | --- | --- |
| 地上总层数 | 历史规划图7F、OSM八层、电梯9/9和8/8 | 冲突未解；表中没有各停站楼层标识或楼栋坐标，不改成七层或九层 |
| 地下或半地下层 | 第6张照片有低窗带；电梯停站数量不同 | 不能据此断言存在地下室，也不以“七层加地下层”强行消解冲突 |
| 屋顶局部高体量 | 新照片均无完整最高屋面 | 不添加电梯机房、屋顶层或统一抬高整栋 |
| 入口 | 已有台阶和柱式入口近照 | 待确定墙段、方位和尺度；保留现有示意入口 |
| 名称 | 历史环境相关牌匾和题名石 | 保留候选历史名称，不把它写成已确认的现行地图名称 |
