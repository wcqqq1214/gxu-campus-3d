# 最终树位占地筛选

## 本批修复

原来的数据准备末尾只重跑两处显式禁植区。建筑、道路、水体和运动场的筛选分散在较早步骤；后续新增树位或调整场地时，最后一步不能重新保证占地约束。

在真实数据的隔离副本中，末尾注入建筑、道路、水体、运动场内各一株测试树。修改前四株全部保留；修改后通过实际 `prepare_vegetation()` 全部排除，原3,050株顺序和属性保持。测试树未写入生产数据。

## 实现和范围

[统一占地规则](../scripts/vegetation_exclusions.py)由[最终植被准备](../scripts/vegetation_data.py)调用。通用铺面按基础设施、外围场地、校园主路、入口场地的覆盖顺序解析，移除已替换及隐藏面，再纳入专用道路层、建筑外环和内院、运动场地、入口铺地、普通广场及已建岸顶。

当前共897个占地范围：448个建筑多边形、381个道路范围、38个运动范围、27个水体范围，以及入口场地、普通铺地和岸顶各1处。同一设施可有多个范围，数量不等于现实设施数。

此规则禁止**树干中心落在占地范围内或边界上**，保留建筑内院孔洞。它不是树干体积或树冠三维碰撞检查，也不把建筑占地解释为封闭实体。空间索引和预处理几何避免对每株树重新计算整个校园复杂铺面。

随后继续执行原有两处开放空间树冠排除；模型构建时继续执行最终贴地以及建筑表面与[闭合组件包含检查](VEGETATION_SOLID_CLEARANCE.md)。普通道路上方的树冠投影不会被占地规则单独删除。
