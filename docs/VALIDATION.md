# 验收记录

日期：2026-09-09。实现和模型检查在 Apple M5、16 GB 内存、macOS 26.5.1 上完成。桌面浏览器为 Codex 内置 Chromium 预览，通常为 1280 × 720；移动检查使用同一设备上的 390 × 844 视口，**不是手机真机测试**。

## 已完成

- TypeScript 类型检查、Oxlint、8 项 Node 测试、生产静态导出通过。npm audit 未报告已知漏洞。第三方 vendored UI、Draco 解码器和生成物不进行项目源码规则的重新 lint；业务代码保留严格检查。
- 坐标往返、米制比例与南北方向；关系成员去重；庭院内环及三角索引；建筑目录/地标/GLB 稳定 ID；分区与建筑集合一一对应；GLB 内置纹理与 Draco 声明；原始高程及来源日期字段验证通过。
- 南门位于综合实验大楼南侧、图书馆位于综合体育馆东侧等关系通过自动检查，结合校方导览图和外观资料抽查校园轴线、道路与湖塘。
- 10 处地标各生成两个源模型视角并人工检查，见 [建模记录](MODELING.md)。普通建筑在图书馆周边与教学/生活区近景检查了窗列、阳台、屋顶和入口。
- 搜索“南大门”“图书馆”、列表定位、来源展开、关闭详情通过；7 项图层关闭后只保留基础地形，再开启可恢复。
- 晨光、日间、黄昏、夜景和流畅档切换通过；阴影、窗光与实例数量相应变化。
- 巡游开始、暂停、继续、下一站、手动拖动暂停通过；缩放、俯视、倾斜鸟瞰、正北和全景复位通过。全屏调用由浏览器支持能力决定，嵌入式浏览器的窗口全屏行为不作为普通 Chrome / Safari 的验证替代。
- PNG 导出已实际保存并打开检查，包含三维画面和底部 OSM 署名；内置浏览器没有上报标准 download 事件，但文件确实写入下载目录。
- 390 × 844 移动布局、选择地标后收起底部菜单、再次展开通过。触屏双指操作由 Three.js OrbitControls 实现；真实手机的多点触控、热降频、续航及 GPU 内存未测试。
- 本地静态服务器模拟基础模型首次 503，提示错误后“重试”恢复。模拟 east.glb 首次 503，基础校园与独立地标仍保留，重试后分区恢复。
- 开发模式的 `?test-webgl-unavailable` 用来触发相同初始化失败分支，确认 WebGL 不可用提示。此测试开关仅在开发模式生效。

## 资源预算

| 项目 | 实际大小 |
| --- | ---: |
| 基础校园 base.glb，含嵌入纹理 | 4,982,460 bytes |
| 植物模板 trees.glb | 21,892 bytes |
| 首屏模型与纹理合计 | **5,004,352 bytes，约 5.00 MB** |
| 所有 GLB 合计，按需加载 | 24,800,344 bytes |
| 可编辑 .blend | 73,227,527 bytes |

首屏精细档 ≤ 12 MB、流畅档 ≤ 6 MB 均通过。两档共用轻量基础文件，画质差异体现在植被实例、阴影、像素比和普通建筑分区近景。这个预算仅计算模型与纹理，网页 JS、JSON 目录、解码器另计。所有贴图嵌入模型，未依赖运行时第三方地图服务。

## 本地运行观测

1280 × 720 静态预览，基础场景像素比 1.75，相机移动样本约 **39 FPS**；较早图书馆近景样本约 **33 FPS**。流畅档将像素比降至 1.25，相机移动约 **27 FPS**（主动限制至约 30 FPS）。渲染按需进行，静止时不持续重绘；调试面板的 FPS 是最近一段活动帧采样，不是闲置帧率。

本地缓存命中时基础模型就绪约 **0.35 秒**，开发首载样本约 **3.70 秒**。它们不是互联网首访结果。`readyMs` 从浏览器页面时钟起算，在基础 GLB 就绪时记录，植物随后载入。

调试面板提供 `performance.memory.usedJSHeapSize`（浏览器支持时）、几何数量、纹理数量、三角形、Draw Calls、累计 GLB 字节及像素比。此次内置浏览器多轮测试的报告堆大小约 530—842 MiB；这是浏览器报告值，可能包含共享/回收尚未完成的开销，**不是独占物理内存或 GPU 显存测量**。正式站点的首访观测另行补录。

## 复现故障检查

```sh
npm run build:pages
npm run preview -- --fail-once=base.glb,east.glb
# 打开 http://127.0.0.1:4300/gxu-campus-3d/
# 基础模型首次失败，重试；选择图书馆，分区首次失败，再重试。
```

调试面板：在网页地址后增加 `?debug`。正式测试无需输入任何 API 密钥。
