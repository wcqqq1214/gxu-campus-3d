# 实验大厅：内缩蓝顶与入口取证接续

2026-09-21，接续[平台四分部体量](CIVIL_PLATFORM_MASSING.md)。本批修正 `way/957404988` 南大厅蓝色屋面铺满轮廓的问题，保留大厅高度、上部窄窗、低翼、门厅、九层北楼及原入口。主体仍为部分校准，不增加整栋完成数。

## 屋面依据与采用参数

[学校2022年拆除采购公告](https://www.gxu.edu.cn/info/1364/30576.htm)所附[范围航拍](https://www.gxu.edu.cn/system/_content/download.jsp?urltype=news.DownloadAttachUrl&owner=1556120285&wbfileid=3792656)可见：新大厅蓝色覆盖层四周有连续深色边带，外缘另有浅色墙边。原图已在前批取得，本轮重新核看新平台局部；它与红色编号1的旧大厅是不同对象。照片时点限制见[对象识别记录](CIVIL_LAB_IDENTIFICATION.md)。

采用**等宽1.2米内缩**作为照片约束估算，不将像素尺寸转换成测绘尺寸。大厅仍高13.2米，蓝面及深色边带在同一简化屋面标高，原0.8米通用白色女儿墙保持。真实屋顶微坡、排水设施、边带宽度与女儿墙尺寸仍待核对。

| 屋面部分 | 采用面积 | 状态 |
| --- | --- | --- |
| 蓝色中心面 | 约1485.721平方米 | 估算内缩边界的派生面积 |
| 深色边带 | 约207.733平方米 | 同上；不是新增建筑面积 |
| 合并屋面 | 约1693.454平方米 | 与原厅体屋面轮廓相同 |

两种材质使用相接的三角面分区，没有上下叠加的共面色块。现有分部屋面配置新增可选 `inset`，仅支持实体平顶的 `blue-metal` 覆盖层，拒绝非有限宽度、范围外值、侵蚀后消失或分裂的屋面。内院保留为空，不用边带填院落。

逐面法线检查曾发现三个共线边界点在 float32 导出后产生约0.000334平方米的反向薄片。修复仅在屋面三角化前清理小于0.1微米的共线噪声，建筑主体和立面锚点保持；没有放宽法线检查。修复前诊断留在本机工作目录，交付以重建后资产及验证报告为准。

## 验证与接续

固定几何检查覆盖四边深色带、蓝色内边界两侧、屋面总面积与朝上法线，同时保留上一批的四体量、接缝、窗带、外墙和大厅无中间楼板检查。源文件、基础与近景使用相同标准；旧铺满蓝面的模型作为反例。最终数据、资产、浏览器与性能结果见[本批汇总](model-checks/refinement/s2-platform-roof-summary.json)。

231项Python、59项Node、类型检查、lint和模型/Pages构建通过。源文件、实际基础与近景各49项检查通过，旧模型在边带位置仍为蓝色而失败。数据检查证明原体量、立面、入口和高度保持；仅平台综合楼源对象变化，其他532个非树对象及3,063株树保持。只有基础GLB和本栋近景区块更新，其他67个GLB与93个基础节点保持，69个生产模型一致。首屏5,392,244字节，比上一批减少908字节，最大普通近景区块1,684,868字节。

独立复核命令（在仓库根目录运行，使用新前缀保留历史报告）：

```sh
blender --background --python-exit-code 1 --python blender/validate_civil_platform.py -- --inset-roof --report-prefix=s2-platform-roof-local
```

普通建筑、实际树冠与道路建筑检查通过；11张前后、植被开关、夜景和手机尺寸画面均已核看。较高南侧镜头改善了屋面的可见性，但不替代南门真实形制的资料核对。

最终性能为精细60/60/60 FPS、流畅28/27/28 FPS。相对同系统S0，两档中位帧率变化0%/−6.67%，三角形增加4.51%/10.82%，绘制调用增加1.28%/13.69%，均通过既定预算。三次LOD往返无错误；26次CPU快照在计时窗口未记录到超过2%阈值的Python/Blender计算。单次流畅档27 FPS的波动保留在报告中，没有剔除该次结果。

下一步先将圆柱玻璃门厅与现有弧形分部定位，再补大厅人员/构件入口及接路；不能把人员入口照片当成构件大门。北综合楼立面和屋顶、低翼层数与细部、旧大厅历史占地仍待完成。共22个校准对象，1栋首轮整栋通过、21个部分校准，完整计划目标保持。
