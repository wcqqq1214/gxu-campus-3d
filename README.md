# 西大 · 云游校园

**[打开三维校园 →](https://wcqqq1214.github.io/gxu-campus-3d/)** · [数据依据](docs/DATA.md) · [Blender 重建](docs/MODELING.md) · [菜单说明](docs/DESIGN.md) · [验收记录](docs/VALIDATION.md)

![广西大学三维校园实际网页截图](docs/screenshots/overview.png)

以 **Three.js + Blender** 复现广西大学大学东路主校区，涵盖东、西、北校园与校界外约 300 米的周边环境。自然建筑配色、浓绿乔木和棕榈、湖塘、道路与运动场，配合轻薄浅色菜单和深绿强调色。网页无需账号、地图密钥或后端。

OSM 地图快照为 **2026-09-09 07:57:13 UTC**。当前包含 **435 栋校内建筑、45 栋周边建筑、11 处精选地标和 3,178 株示意树木**。近期核对采用 2024—2026 年校方资料，并在缺少近期外观时引用更早的官方照片或视频。获取日期不代表所有建筑资料都在当年更新。

2026-09-09 修正：南大门已按 2022—2026 年可核对照片重建为现三跨石门，并绑定真实 OSM 门楼轮廓；汇学堂入口改为朝东。[南门近景](docs/screenshots/south-gate-current.png) · [汇学堂朝向](docs/screenshots/huixue-east.png) · [建模与年代记录](docs/MODELING.md)。

## 体验

- 搜索精选地标；列表、地图标注、建筑点击与自动巡游共用 11 处精选名单。普通建筑保留展示，不进入索引导航。
- 独立开关建筑、植被、道路、水体、运动场、周边建筑与名称标注。
- 晨光、日间、黄昏、夜景；自动、精细、流畅画质。
- 旋转、平移、缩放、俯视、倾斜鸟瞰、正北、全景复位和全屏。
- 按 11 处精选地标顺序自动巡游，支持暂停、继续、前后跳站；手动操作暂停巡游。
- 导出带 OSM 署名的场景 PNG。手机使用可收起的底部菜单。

## 本地运行

需要 Node.js 24 或更新版本。

```sh
npm ci
npm run dev
```

使用终端打印的 Local 地址。构建及检查：

```sh
npm run typecheck
npm run lint
npm test
npm run build:pages
```

可运行 `npm run preview`，在 `http://127.0.0.1:4300/gxu-campus-3d/` 验证静态包。

GitHub Pages 发布包位于 `out/`，默认路径为 `/gxu-campus-3d/`；设置 `PAGES_BASE_PATH=''` 可生成站点根目录版本。不要直接通过 `file://` 打开网页。

## 模型和数据

- [可编辑 Blender 源文件](blender/gxu-campus.blend)：米制尺寸、具名建筑、材质及集合，原始压缩纹理已打包。
- [GLB 资源](public/models/)：校园基础模型、东/西/北近景分区、11 个独立地标及树木模板；几何 Draco 压缩，材质采用自制 JPEG 纹理。
- [数据目录](public/data/)：GeoJSON、建筑目录、地标目录、模型清单、来源记录、原始及处理后高程、示意树木。
- [数据快照](data/snapshots/)：保留版本和编辑时间的 OSM 快照、DEM 瓦片及查询，可离线恢复并重建。

11 处精选地标包括南大门、图书馆、汇学堂、大礼堂、综合体育馆、大学生活动中心、第六教学楼、第二教学楼、综合实验大楼、计算机与电子信息学院、留学生公寓。其余建筑按真实轮廓生成窗格、屋顶、入口与宿舍阳台；近景按区域加载。图层与资料目录用稳定的 OSM ID 关联，关系成员去重、内院保留。

**精度边界：**这是一项公开数据驱动的校园展示复现，未经过校园实地测绘。370 栋建筑高度按类型估算；部分地标高度参考照片估算，第二教学楼立面主要按类型推定。照片未覆盖的细节、植物种类与树位也包含推定。北校园及周边以现有 OSM 覆盖为准，未绘制的位置没有虚构补建。历史 DEM 经过湖岸和基底局部平整，不能作工程高程依据。详情见[数据年份与精度](docs/DATA.md)。

东西田径场已重建：连续分道线、平整足球内场、完整足球标线和球门；西场补充开放主席台与分色座席。运动场保留在三维场景与运动场图层中，场地数据中的复原依据标明近期照片和估算尺寸。查看[建模说明](docs/MODELING.md#两处田径场)。

## 发布

`main` 分支经 [GitHub Actions](.github/workflows/pages.yml) 检查、构建和发布到 GitHub Pages；所有地图、模型、纹理与 Draco 解码器均随站点托管。仓库 About 中也设置了在线地址。

提交信息使用全角冒号和中文，例如：

```text
feat：完成广西大学三维校园与公开发布
```
